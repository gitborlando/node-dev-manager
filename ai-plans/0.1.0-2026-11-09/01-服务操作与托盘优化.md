# 服务操作与托盘优化

## 需求与实现

- 每个 Tab 内合并启动/刷新操作：未运行显示三角形，运行后显示刷新图标；处理中禁用并显示旋转状态。
- 删除停止和独立清空按钮；刷新在旧进程退出后、新进程启动前自动清空对应服务输出，托盘刷新也使用同一逻辑。
- “＋”添加新服务；笔尖位于最小化左侧，编辑当前选中服务。
- Tab 可拖动调整顺序，并保存排列，托盘也沿用该顺序。
- 输出保持只读，支持鼠标选择、Ctrl+C / Ctrl+Shift+C、Ctrl+A 全选及右键复制选区。
- Windows 托盘右键列出登记服务，根据运行状态显示启动或刷新，处理中禁用。
- 登记配置写入 Electron 用户数据目录的 project-configs.json，首次自动迁移原 localStorage 配置；写入串行化并使用临时文件替换，读取损坏配置不覆盖原文件。
- 已打包 Windows 程序通过 --autostart 标识登录启动，并启动全部登记服务；普通启动及开发启动不自动启动服务。
- 主进程缓存近期输出，以便开机启动及渲染器重新加载后恢复显示；修正空输出首条日志、日志上限滚动和 StrictMode 订阅清理问题。

## 校验范围

- 前端：pnpm typecheck 通过。
- Electron：pnpm exec tsc --project tsconfig.electron.json --noEmit --esModuleInterop 通过。原有默认 Node 导入方式需要该兼容选项，未修改全局编译配置。
- 恢复 pnpm dev 开发桌面运行，不额外执行完整 build、打包或开机重启测试。
- Windows 登录自动启动需在打包版本运行后注册，本轮不修改开发环境的系统启动项。
